# 换手机/重新部署完整流程（SETUP）

从零开始，把笔画输入法完整装好（换手机、重装元书、或重装系统后照做）。

## 准备文件

需要两个文件（在项目 dist/ 下）：

| 文件 | 内容 |
|---|---|
| `dist/stroke_zh.zip` | RIME 方案（单字 + 词组 + 预测库） |
| `dist/stroke_zh.cskin` | 元书键盘皮肤（九宫格笔画键盘） |

> 文件缺失时先构建：见 README「构建」章节。

## 步骤

### 1. 安装元书输入法

App Store 搜索「元书输入法」（开发者：啸 付，RIME 引擎，免费下载+订阅/永久授权）。

### 2. 导入 RIME 方案

1. 打开元书 App → 输入方案
2. 导入 `stroke_zh.zip`（文件 App 分享给元书 / 元书打开）
3. **部署**（Deploy）——等待完成（首次约 10-20 秒）
4. 确认输入方案列表里有「笔画·增强」

### 3. 导入键盘皮肤

1. 文件 App 长按 `stroke_zh.cskin` → 分享 → 元书输入法
2. 元书 → 键盘设置 → 键盘皮肤 → 选中「笔画增强」
3. 若皮肤不显示：**删除皮肤重新导入**（元书有时缓存旧配置）

### 4. 添加系统键盘

1. 设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → 元书输入法
2. 打开仓「允许完全访问」（RIME 需要）
3. 打开一次元书 App 完成初始化

### 5. 验证

在任意输入框（元书 App 内体验输入法）测试：

- **单字**：打 `nphhhpszhhh` 出「着」（大陆笔顺）；打 爱/办/贝/张/这/啰/瞭（7953 字）
- **词组**：打 `phshpsns`（我们）、`nhpnszhh`（效果）、`pspzzphz`（你好）——每字前 4 笔；成语：三长两短/人山人海（8.6 万词）
- **清除**：主键盘行2「清除」键一键清空
- **单字提速**：打 `ps`（的前2笔）→「的」前 4；`pn`（个前2笔）→「个」前 4（56 个高频字已加权）
- **英文键盘长按**：a→àáâäæāå、0→° 等拉丁变体（仿 iOS 系统）
- **左列**：不打字显示标点（打字时元书自动变拼音提示，皮肤无法覆盖——已知限制）
- **预测**：打「你」上屏 → 候选栏出现「们/好/家」（上屏后预测）
- **标点**：左下角 #+= 进符号键盘输入标点；英文键盘无独立逗号/问号键（与中文底部行对齐）

## 常见问题

| 问题 | 解决 |
|---|---|
| 皮肤导入后不显示 | 删除皮肤 → 重新导入（缓存问题） |
| 候选乱码（方框？） | 方案用了 GB2312 常用字过滤，理论上不会；若出现说明部署了旧版 |
| 打不出某字 | 字不在 GB2312（生僻字）；或笔顺记错（查 docs/STROKE_DATA.md） |
| 打不出某词 | 词不在词库（jieba 缺失如「很好」）；告诉我加补充 |
| 部署报错 | 确认 zip 完整；predict.db 在 zip 内 |
